# ShareMouse v0.1.0-alpha.1

This is an early alpha build for evaluation.

## macOS

Requires macOS 14 or newer. Open the DMG and drag ShareMouse.app to Applications. The signing and notarization status depends on the environment used to build the package.

## Windows

Requires Windows 11 x64. Run the setup program and approve the administrator prompt required for input integration. The installer includes the .NET runtime.

## Data and permissions

ShareMouse stores its identity, preferences, and history on the local computer. Uninstalling the Windows application keeps this data. The app requests operating-system permissions only for the feature that needs them. Pairing and remote control require approval on the receiving computer.

An alpha package is a preview and may have platform, hardware, or workflow limitations.
